[B]2.2.8[/B]
• The player controls' information button works. It was written as a bare "Info", the way Kodi's own skin writes it, and that action never arrives: it is handed to the window manager, where the player controls are the topmost modal dialog and Kodi's video OSD only answers to the button that closes it, so the action is dropped there and never reaches full screen video, which is what opens the dialog. The button now closes the controls and opens the programme information dialog by name, the same way the channel and guide buttons beside it already worked
• The guide behind the player controls shows each programme's own picture instead of the same placeholder on every row. A programme's picture does not arrive as thumbnail artwork - Kodi files it as the item's icon - so the row only ever found the placeholder. The channel's logo stands in where a programme has no picture of its own, and the placeholder is still there for the case where there is neither

[B]2.2.7[/B]
• Installing the skin now brings the two EON helper add-ons with it: EON Remote Keys, which gives the remote's Up and Down one meaning everywhere, and EON Guide Defaults, which starts Kodi's guide settings at seven days of history, three days ahead and a refresh every 48 hours. Neither can live inside the skin - Kodi only reads keymaps from the profile, and only a service add-on can write a system setting - so until now they had to be found and installed by hand on every device

[B]2.2.6[/B]
• The player controls no longer print "Left / right to seek" on top of the behind-live readout. Both labels are centred on the same line under the timeline, and the hint only checked that no seek was in progress, so on a rewound live stream the two strings were drawn over each other and neither could be read. The readout wins that spot now: the hint appears when the timeline has focus and there is nothing behind-live to report, which is the same rule the infobar already used for its "LIVE" label. That rule is one expression both windows share, so the slot cannot end up with two owners again

[B]2.2.5[/B]
• "Other / Unknown" is gone from the rest of the skin too, not just the player infobar: the programme line in the channel list, the guide, the programme information dialog and PVR search all drop it the same way, and keep whatever else that line was carrying - the separator in front of it goes with it rather than being left dangling
• The guide no longer ends the selected show's details with a "Next" line that had nothing to do with it. That line is the channel's next programme counted from right now, which is the right answer beside a channel but not beside a show: picking one that ended at 20:00 still read "Next 20:45". The description now uses that space instead, so more of it fits before it runs out of room. Beside a channel, in the home panel and the channel list, the line stays exactly as it was

[B]2.2.4[/B]
• "Other / Unknown" no longer sits under the title of a programme. Kodi has no state for "the provider sent no genre" - a tag without genre ids is still reported back as that placeholder - and this backend sends none, so it appeared on every programme while saying nothing. The line now falls through to the year, or disappears if there is nothing else to put there, and a real genre still shows the moment one arrives

[B]2.2.3[/B]
• The panel that says "Importing guide from clients" no longer draws over the clock. It sits on top of the header and its fill was see-through, so the time and date read straight through it, right beside the percentage. It now uses the same opaque panel and accent stripe that notifications do, so it covers that corner cleanly while it is up
• Its progress bar is a straight line again. Nothing set the bar's textures, so it fell back to the rounded default - a 24x24 texture drawn with a 6 pixel border, which at 6 pixels tall leaves the rounded ends nowhere to go and crushes them into a lumpy shape. The channel list already drew its progress bars as plain straight lines; the guide import panel and the programme details bar now match it

[B]2.2.2[/B]
• Pressing back out of full screen TV now lands on the channel list, on the channel you were watching, instead of on the side rail. Home forced focus to the rail every time the window was entered, which also stopped Kodi from remembering where you had been; the rail is still the fallback for the case it was there for - a channel list that is still empty cannot take focus - but as soon as the list has channels in it, focus goes to the list. Coming back from the guide or from settings behaves the same way

[B]2.2.1[/B]
• Fixed the current value being unreadable in every list Kodi asks you to pick from - the guide's "Default select action" is one. Defaults.xml gives every label selectedcolor "selected", and in this skin "selected" is the accent, the same colour a focused row is filled with, so the selected row drew accent text on an accent background. Every list label that sits on that fill now restates its selected colour, and the validator fails on one that does not
• Fixed the same rows going near-black on near-black once the list lost focus. The row body was always drawn in the inverted colour meant for the accent fill, even behind the dim fill used when the list is not focused; its colours now follow the list's focus state. Ten dialogs share that row, so they were all affected
• The bottom bar now names the installed EON PVR client and this skin, with their versions. Both are read from the add-ons at runtime rather than written into the skin, so they cannot drift from what is actually installed, and the client half is left out on a Kodi that does not have it

[B]2.2.0[/B]
• No visible changes: this release is the skin rebuilt on shared building blocks, so the parts that have to look and behave alike no longer exist as separate copies that can drift apart. The on-screen keyboard, the infobar and the player controls are the ones that had copies
• The infobar and the player controls now draw their seek marker, timeline labels, behind-live readout, seek amount, panel and REC/state icons from one definition each, instead of two that had to be edited in step
• The on-screen keyboard's 59 keys come from two definitions rather than 59 hand-written blocks
• Removed code nothing used any more: a leftover variable, a leftover parameter, and comments describing behaviour that had already been replaced
• Texture generation runs 6x faster, and the validator and the publish script no longer trip over deprecations in newer Python

[B]2.1.10[/B]
• Fixed buttons missing from several dialogs. A DialogButton hides itself when it has no label, because Kodi hides-but-does-not-label the buttons a dialog is not using - so any button I forgot to label vanished. The add-source dialog was missing Browse, Add and Remove, and the on-screen keyboard was missing OK, Cancel and IP address, which left no way to accept what you typed. Labels checked against Kodi's own skin, control by control, across every dialog in the skin
• The validator now fails on a DialogButton with no label param, so a button cannot silently disappear again
• A confirmation with no body text - the exit prompt is one - now says "Are you sure?" under its heading, instead of showing the heading alone with nothing to confirm

[B]2.1.9[/B]
• The rewind/forward amount now appears the instant you press, instead of a beat later. It was keyed on Player.SeekOffset, which Kodi only fills once the seek has been performed; the immediate value is Player.SeekStepSize, which is what Kodi's own skin shows. The time beside it jumps to the seek target on that same first press
• The player controls now draw the same white seek marker the infobar does. Kodi only drives its 401/403 seek controls inside the infobar, so the marker here is fed from PVR.TimeShiftSeekbar on live TV and Player.Seekbar otherwise

[B]2.1.8[/B]
• Fixed seeking with the player controls open doing nothing at all. 2.1.7 sent the seek action to a single window, and Action(x,window) is delivered only to that window, which skips the global seek handler where seeking actually lives. Verified on a real box: a step back now reports -00:10 and commits
• Fixed the infobar disappearing and coming straight back, over and over. Kodi restarts a skin timer the moment it stops if its start condition is still true, and "playback is playing" is always true - so the timer looped. It now runs for the length of playback and the infobar keys off the elapsed seconds
• Fixed the player controls closing after about two seconds instead of five. The close is now driven purely by Kodi's own idle timer, which already restarts on every keypress, instead of a reset condition of the skin timer's own

[B]2.1.7[/B]
• Seeking with the player controls open now works exactly as it does with them closed: left/right run the same seek steps and show the same running -30 / -1:00 / -3:00 amount. It used to be a percentage scrub, because Kodi always consumes an arrow press inside the focused control, so the timeline itself now fires those seek actions
• The controls open with the timeline focused, so arrows seek straight away; down reaches the buttons
• The player overlays now sit on a light see-through panel, so the text reads over bright video without hiding the picture
• The infobar appears for five seconds when playback starts, the same as it does when you change channel

[B]2.1.5[/B]
• Fixed the huge white disc when the timeline is focused, and the thick white band while rewinding. Kodi sizes a slider nib and a progress handle by control-height / background-texture-height, so the 2px transparent background inflated a 12px handle to 72px - and on a progress control the same factor applies to width, which stretched it into a band across the bar. The marker is now a slider whose bar texture is the marker itself at alpha 00, exactly as Estuary does it
• Fixed the live TV seek marker sitting in the wrong place: it was driven by control 402, which measures progress through the *programme*, on a bar that spans the timeshift window. It now uses 403, the timeshift seek position, which is the same scale as the bar
• Fixed fast-forward and rewind in the player controls just pausing. Both fired PlayerControl(Play) first, and Play toggles pause
• The seek offset (+3:00 and so on, as it adds up over several presses) is now large and accented, and "behind live" is no longer dim grey
• The home menu is icons only, with no text
• Removed the key-hint strip at the bottom of lists; the item counter stays
• The player controls focus the button row rather than the play/pause button specifically - Kodi refuses to focus that button when the player reports no pause support, which left the controls with nothing focused
